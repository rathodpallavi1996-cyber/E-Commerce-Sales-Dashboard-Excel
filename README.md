# E-Commerce Sales Dashboard

## About the Project

I created this project using Excel to practice data analysis and dashboard creation with an e-commerce sales dataset.

The main purpose of the project was to understand sales, profit, quantity, and order performance and present the results in an easy-to-understand dashboard.

## What I Worked On

- Checked and worked with the sales data
- Calculated total sales and profit
- Calculated total quantity and orders
- Compared sales between different regions
- Analyzed monthly sales
- Created charts for better understanding
- Designed a final Excel dashboard

## Dataset

The dataset contains more than 51,000 records with details such as:

- Order ID
- Order Date
- Customer details
- Product details
- Region
- Sales
- Quantity
- Discount
- Profit
- Shipping Cost

## Dashboard

The final dashboard shows:

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Sales by Region
- Monthly Sales Trend

## Tools Used

- Microsoft Excel
